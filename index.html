Glossary

Uptime
Share of synthetic checks that returned a healthy page. 99.9% allows about 43 minutes of downtime a month.
Apdex (Application Performance Index)
User satisfaction with response time, from 0 to 1: (satisfied + tolerating ÷ 2) ÷ all requests, against a threshold T. 0.94+ excellent, 0.85–0.93 good, 0.70–0.84 fair, below 0.70 poor.
LCP (Largest Contentful Paint)
When the main content becomes visible. Good ≤ 2.5 s, poor > 4 s.
INP (Interaction to Next Paint)
How quickly the page responds to taps and clicks. Good ≤ 200 ms, poor > 500 ms.
CLS (Cumulative Layout Shift)
How much the layout jumps while loading. Good ≤ 0.1, poor > 0.25.
TTFB (Time to First Byte)
How long the server or CDN takes to start responding. Good ≤ 800 ms, poor > 1,800 ms.
p75 and Core Web Vitals
LCP, INP and CLS are Google's Core Web Vitals, measured on real visits. p75 means 75% of page loads were at least this good.
